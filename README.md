# Aurelian FM–6

6つの正弦波オペレーターをつないで、エレピ、ベル、ベースを作る楽器です。Rustの音源部は単体でも使えます。ブラウザー版は同じ音源をWebAssemblyにコンパイルし、AudioWorkletから呼び出します。ライブラリの追加やサーバーへの音声送信は不要です。

## まず弾く

ZIPを展開し、**Play-FM6.html** をPCのChromeまたはEdgeで開きます。このファイルは準備なしで試せるJavaScript参照版です。**▶ フレーズ試奏** を押すと、選んだ音色で短いコードとメロディーが鳴ります。音色名の右端をクリックするとプリセットを切り替えられます。Rust版も同じ画面で操作できます。

| 操作 | 方法 |
| --- | --- |
| 白鍵 C・D・E・F・G・A・B・C | A・S・D・F・G・H・J・K |
| 黒鍵 C♯・D♯・F♯・G♯・A♯ | W・E・T・Y・U |
| 強く弾く | Shiftを押しながら打鍵 |
| オクターブ変更 | 鍵盤上の − ／ ＋ |
| 全音停止 | Esc または「全音停止」 |
| 音色の保存・再利用 | 「音色を書き出す」でJSONを保存し、「音色を読み込む」で復元 |

マウスでも鍵盤を弾けます。設定変更は次の打鍵から効き、鳴っている音には打鍵時の設定が残ります。音量は演奏中にも変えられます。プリセットを切り替える前に、残したい編集をファイルへ書き出してください。

## 波形モニター

鍵盤を押すか「フレーズ試奏」を押すと、OP1〜OP6と最終出力が同時に動きます。7つの窓は同じ12ミリ秒の区間を表示します。「縦倍率」を×2・×4にすると、小さい波形の形を拡大できます。演奏音量は鍵盤右上の「音量」で調整します。

| 表示 | 波形を取り出す位置 |
| --- | --- |
| 緑のキャリア | 変調を受けたオペレーターの、エンベロープ・Level・ベロシティ適用後の出力 |
| 橙のモジュレーター | 次のオペレーターの位相を動かす信号。キャリアと同じ振幅目盛で表示 |
| 最終出力 | すべての声のキャリアを合成し、リミッターとマスター音量を適用した後の出力 |

和音では、押している鍵のうち最後に押した1音を6つのOPで追います。鍵を離すと残った鍵に戻り、すべて離すとリリース中の最後の音を追います。「表示音」にその音名が出ます。音色やアルゴリズムを切り替えても、響いている声の表示には打鍵時の配線が使われます。

**試してみるには**「Init Sine」でAを長押しします。動くのはOP1と最終出力です。いったん離し、OP2のLevelを60%にしてAをもう一度弾くと、OP2に正弦波が現れ、OP1と最終出力の形が変わります。Aを押したままDを加えると、OP表示はE4に切り替わり、最終出力にはC4とE4の両方が現れます。

## Rustで音を鳴らす

[Rustの公式インストーラー](https://www.rust-lang.org/tools/install)で安定版RustとCargoを用意してください。以下のコマンドはCargo.tomlがあるフォルダーで実行します。

### PC上で音源部を試す

```sh
cargo test --lib
cargo run --release --example first_patch
```

生成された **first-patch.wav** を再生してください。0秒と2秒で同じA3を弾いています。後半でOP2のLevelを0から0.8に変えたため、打鍵直後に倍音が加わります。**examples/first_patch.rs** の `ratio = 2.0` を `2.71` に変え、もう一度実行すると、整数比と非整数比の響きを比較できます。再実行時は同名のWAVを更新します。

### Rust音源を鍵盤から弾く

```sh
rustup target add wasm32-unknown-unknown
cargo run --release
```

生成された **Aurelian-FM6.html** をPCのChromeまたはEdgeで開いてください。右下に **RUST / WEBASSEMBLY** と表示されます。音声処理はRustが担当し、ブラウザーは鍵盤入力、画面表示とオーディオ出力を担当します。Rustソースを変更したときは、もう一度 `cargo run --release` を実行してページを開き直します。

ブラウザーがローカルファイルでAudioWorkletを制限する場合は、Python 3でプロジェクトフォルダーを配信できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

WindowsでPythonランチャーを使う場合は先頭の `python3` を `py -3` に変えます。ブラウザーで `http://127.0.0.1:8000/Aurelian-FM6.html` を開きます。試奏版には末尾を `Play-FM6.html` にします。終了は端末でCtrl+Cです。

## エレピのアタックを作る

1. **Init Sine** を選んでAを弾きます。聞こえるのはOP1の正弦波です。
2. **OP2** を選び、**Level** を0%から60%に上げて弾き直します。OP2がOP1の位相を揺らし、同じ音程でも響きが明るくなります。
3. OP2の **Sustain** を0%、**Decay** を0.2秒にします。打鍵直後だけ倍音が出て、伸ばすと丸い音に戻ります。Decayを1秒にすると、その明るさが長く続きます。
4. **Transit EP** に切り替えます。OP4の **Level** を下げて同じフレーズを再生すると、OP3に加わっていた高域の打音を聴き分けられます。

| プリセット | 聴きどころ |
| --- | --- |
| Transit EP | 3組のペアで、芯、少しずれた余韻、短い打音を重ねたエレピ |
| Aurelian Bell | 2.71や3.51といった非整数の周波数比による金属的な響き |
| Diesel Bass | 0.5倍の低い芯と、4段直列の短いアタック |
| Init Sine | OP1を単独で鳴らした音作り用の初期音色 |

## 発音の仕組み

オペレーターには正弦波の位相、周波数比、出力レベル、独立したADSRがあります。1サンプルずつOP6からOP1へ計算します。キャリアの出力を足し合わせて音声にし、モジュレーターの出力は接続先の位相に足します。A4は440 Hz。倍音は周波数比と変調の深さの両方で変化します。

| 接続 | 信号の流れ（番号はOP） | 出力するOP |
| --- | --- | --- |
| 01 | 2 → 1、6 → 5 → 4 → 3 | 1、3 |
| 05 | 2 → 1、4 → 3、6 → 5 | 1、3、5 |
| 32 | 6個を並列に加算 | 1〜6 |

いずれもOP6は自分自身へフィードバックできます。16音が使用中なら、リリース中の最古の声、その次に打鍵時刻の最も古い声を再利用します。PC鍵盤の通常打鍵とShift打鍵には異なるベロシティを割り当てています。

DX7の指標は6オペレーター、32アルゴリズム、最大16音、各オペレーターの4レート・4レベルEGです。FM–6の初版は3つの配線と秒単位の線形ADSRに範囲を絞っています。プリセットはオリジナルです。SysEx音色の読み込み、MIDI機器入力、DAWプラグイン、実機の量子化特性の再現は未実装です。

## 編集する場所

| ファイル | 内容 |
| --- | --- |
| src/engine.rs | ボイス割り当て、配線、位相変調、エンベロープ、音声ブロック生成、テスト |
| src/lib.rs | Rust音源をWebAssemblyから操作する入口 |
| examples/first_patch.rs | Rust音源を直接呼んでWAVへ書く最小の聴き比べ |
| web/presets.json | 音色。各OPの配列は周波数比、レベル、Attack秒、Decay秒、Sustain、Release秒の順 |
| web/instrument.html | 日本語の操作画面、パッチの保存、鍵盤と試奏フレーズ |
| web/processor.js | AudioWorklet、Rust音源との接続、準備不要の試奏版用音源 |
| src/bin/build-instrument.rs | Rust音源と画面を単一のHTMLへまとめるビルダー |
