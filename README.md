# Aurelian FM–8

8つの正弦波オペレーターを88通りの配線でつないで、エレピ、ベル、ベース、オルガンを作る楽器です。Rustの音源部は単体でも使えます。ブラウザー版は同じ音源をWebAssemblyにコンパイルし、AudioWorkletから呼び出します。ライブラリの追加やサーバーへの音声送信は不要です。

## まず弾く

ZIPを展開し、**Play-FM8.html** をPCのChromeまたはEdgeで開きます。このファイルは準備なしで試せるJavaScript参照版です。**▶ フレーズ試奏** を押すと、選んだ音色で短いフレーズが鳴ります。曲はボタン右の欄で選べます。プリセットを切り替えると、その音色に合わせた曲が自動で選ばれます。音色名の右端をクリックするとプリセットを切り替えられます。Rust版も同じ画面で操作できます。

| 操作 | 方法 |
| --- | --- |
| 白鍵 C・D・E・F・G・A・B・C | A・S・D・F・G・H・J・K |
| 黒鍵 C♯・D♯・F♯・G♯・A♯ | W・E・T・Y・U |
| 強く弾く | Shiftを押しながら打鍵 |
| オクターブ変更 | 鍵盤上の − ／ ＋ |
| 全音停止 | Esc または「全音停止」 |
| ピッチベンド・ビブラート | 鍵盤の下の WHEEL 欄。ベンドは離すと中央に戻る。「ベンド幅」で最大の幅を1〜24半音から選ぶ |
| MIDI鍵盤で弾く | 鍵盤の下の「MIDI 機器を使う」を押して許可する（下の「MIDI 機器で弾く」） |
| 試奏する曲 | 「フレーズ試奏」右の欄で選ぶ。演奏中に変えると止まる |
| 配線の切り替え | 「接続」の番号欄、または ‹ › で01〜88を選ぶ |
| ProgramとCombinationの切り替え | 画面左上の PROGRAM ／ COMBI |
| 音色の保存・再利用 | 「音色を書き出す」でJSONを保存し、「音色を読み込む」で復元。Programは .fm8.json、Combinationは .fm8combi.json。読み込むとファイルに合わせてモードが切り替わります。FM–6で書き出した .fm6.json もそのまま読み込めます |

マウスでも鍵盤を弾けます。設定変更は次の打鍵から効き、鳴っている音には打鍵時の設定が残ります。音量は演奏中にも変えられます。プリセットを切り替える前に、残したい編集をファイルへ書き出してください。

## MIDI 機器で弾く

USBなどでつないだMIDI鍵盤やMIDIパッドでも演奏できます。PCのChromeまたはEdgeで、鍵盤の下にある **MIDI 機器を使う** を押し、ブラウザーの確認でMIDIの使用を許可します。このボタンを押した時点で音源も起動します。ブラウザーは、MIDI信号だけでは音を出し始められないためです。

| 受け取る信号 | 動き |
| --- | --- |
| ノートオン／オフ | その鍵を鳴らす／離す。ベロシティ1〜127をそのまま強さに使う |
| サステインペダル（CC64） | 踏んでいる間は離した鍵を鳴らし続け、ペダルを上げると止める |
| All Sound Off（CC120） | 余韻も含めてすぐに無音にする |
| ピッチベンド | 鳴っている音も含めて音程を上下させる。幅は「ベンド幅」（初期値±2半音） |
| モジュレーション（CC1） | ビブラートの深さ。最大で±0.5半音、毎秒5.5回揺れる |
| Reset All Controllers（CC121） | ベンドとモジュレーションを戻し、サステインペダルを上げる |
| All Notes Off（CC123） | 押さえている鍵をすべて離す |
| プログラムチェンジ | 今のモードのプリセットを切り替える。0でProgramの01、またはCombinationのC01 |

入力機器は「すべての入力」か1台を選べます。受信チャンネルは「全チャンネル」か1〜16です。COMBIでは、受け取った鍵ごとに、鍵域とベロシティの範囲に入ったTimbreがすべて鳴ります。機器を途中で抜くと、その機器で押さえていた鍵は自動で離されます。ウィンドウを切り替えると、PCのキーボードとマウスで押さえていた鍵は離されますが、MIDI機器の音は鳴り続けます。

ピッチベンドとモジュレーションは、他の設定と違って鳴っている音にもすぐ効きます。どちらもすべてのTimbreと受信チャンネルに共通で、MIDI機器から受け取ると WHEEL 欄のつまみも動きます。値は数ミリ秒かけてなめらかに移るので、MIDIの段階的な値でもプツプツ音は出ません。「全音停止」を押すと、どちらも中央とゼロに戻ります。

## Combination

COMBIにすると、16個のTimbreを重ねたり鍵域で分けたりして鳴らせます。KORGのCombinationと同じ考え方で、Timbreごとに1つのProgram（8オペレーターの音色）を受け持ちます。1つの鍵で、Onで、かつ鍵域とベロシティの範囲に入ったTimbreがすべて同時に鳴ります。

| 設定 | 範囲 | 働き |
| --- | --- | --- |
| On | オン／オフ | オフのTimbreは鳴らない |
| Program | 音色 | プリセットから選ぶと、そのTimbreに音色を丸ごと複写する |
| Volume | 0〜100 | Timbreの音量 |
| Pan | L100〜C〜R100 | 中央では左右とも元の音量。片側へ振ると反対側だけが小さくなる |
| Transpose | −24〜＋24 | 押した鍵から何半音ずらして鳴らすか |
| Detune | −100〜＋100 | セント単位の音程の微調整。100で1半音 |
| Key zone | C−1〜G9 | 鳴らす鍵の範囲。判定は押した鍵で行い、Transpose前の音名で指定する |
| Velocity zone | 1〜127 | 鳴らす強さの範囲。通常打鍵は91、Shift打鍵は124 |

Timbre表左端の番号ボタンを押すと、そのTimbreのProgramを接続・音色編集の欄で編集できます。編集はCombinationの中の複写だけを変え、プリセットや他のCombinationには影響しません。波形モニターは、編集中のTimbreの最も新しい音を追います。

| Combination | 内容 |
| --- | --- |
| EP + Bell Layer | Transit EPに、1オクターブ上のAurelian Bellを重ねる。ベルはShift打鍵（ベロシティ100以上）のときだけ鳴る |
| Bass / EP Split | B3以下でDiesel Bass、C4以上でTransit EP。Octの −／＋ で鳴らす側を切り替える |
| Organ + Choir | Drawbar OrganとGlass Choirを左右に少し振って重ねる |
| Wide Bell | 左右に振って少しずらした2つのAurelian Bellと、1オクターブ下のGlass Choir |
| Drum Kit | 1鍵に1つのドラムを割り当てたキット。C4キック、C♯4リム、D4スネア、D♯4クラップ、F4・G4・A4タム、F♯4クローズド・A♯4オープンのハイハット、C5クラッシュ |
| JD Stage Piano（C06） | JD Glass Pianoの硬いアタックに、Crystal EPと薄いSilk Padを重ねる。強く弾くと1オクターブ上のBell Mistも加わる |
| JD Crystal Air（C07） | Wire Pluckと1オクターブ上のBell Mistの打音から、左右に振ったSilk PadとAir Choirへ広がる4層の音色 |
| JD Wide Horizon（C08） | 左右に振り、±5セントずらしたSweep Stringsに、Silk Padと1オクターブ上のAir Choirを重ねる。長い和音向け |

Drum Kitは、Timbreごとに鍵域を1鍵にし、Transposeで各ドラムの高さを決めています。ハイハットとクラッシュは、87番の配線で、強いフィードバックを持つOP8から7つの非整数比のキャリアを揺らしてノイズに近い響きを作っています。

同時発音数はすべてのTimbreで共有の64音です。足りなくなると、リリース中の最古の声、その次に打鍵時刻の最も古い声を再利用します。出力はステレオです。PROGRAMではTimbre 1だけを中央で鳴らすので、音は左右で同じです。

## 波形モニター

鍵盤を押すか「フレーズ試奏」を押すと、OP1〜OP8と最終出力が同時に動きます。9つの窓は同じ12ミリ秒の区間を表示します。「縦倍率」を×2・×4にすると、小さい波形の形を拡大できます。演奏音量は鍵盤右上の「音量」で調整します。

| 表示 | 波形を取り出す位置 |
| --- | --- |
| 緑のキャリア | 変調を受けたオペレーターの、エンベロープ・Level・ベロシティ適用後の出力 |
| 橙のモジュレーター | 次のオペレーターの位相を動かす信号。キャリアと同じ振幅目盛で表示 |
| 最終出力 | すべての声のキャリアを合成し、リミッターとマスター音量を適用した後の出力 |

和音では、押している鍵のうち最後に押した1音を8つのOPで追います。鍵を離すと残った鍵に戻り、すべて離すとリリース中の最後の音を追います。「表示音」にその音名が出ます。音色やアルゴリズムを切り替えても、響いている声の表示には打鍵時の配線が使われます。

**試してみるには**「Init Sine」でAを長押しします。動くのはOP1と最終出力です。いったん離し、OP2のLevelを60%にしてAをもう一度弾くと、OP2に正弦波が現れ、OP1と最終出力の形が変わります。Aを押したままDを加えると、OP表示はE4に切り替わり、最終出力にはC4とE4の両方が現れます。

## Rustで音を鳴らす

[Rustの公式インストーラー](https://www.rust-lang.org/tools/install)で安定版RustとCargoを用意してください。以下のコマンドはCargo.tomlがあるフォルダーで実行します。

### PC上で音源部を試す

```sh
cargo test --lib
cargo run --release --example first_patch
```

生成された **first-patch.wav** を再生してください。0秒と2秒で同じA3を弾いています。後半でOP2のLevelを0から0.8に変えたため、打鍵直後に倍音が加わります。**examples/first_patch.rs** の `ratio = 2.0` を `2.71` に変え、もう一度実行すると、整数比と非整数比の響きを比較できます。再実行時は同名のWAVを更新します。

### Rust音源を鍵盤から弾く

```sh
rustup target add wasm32-unknown-unknown
cargo run --release
```

生成された **Aurelian-FM8.html** をPCのChromeまたはEdgeで開いてください。右下に **RUST / WEBASSEMBLY** と表示されます。音声処理はRustが担当し、ブラウザーは鍵盤入力、画面表示とオーディオ出力を担当します。同じコマンドで、Rust音源を含まない試奏版 **Play-FM8.html** も作り直します。Rustソースや web/ 以下を変更したときは、もう一度 `cargo run --release` を実行してページを開き直します。

ブラウザーがローカルファイルでAudioWorkletを制限する場合は、Python 3でプロジェクトフォルダーを配信できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

WindowsでPythonランチャーを使う場合は先頭の `python3` を `py -3` に変えます。ブラウザーで `http://127.0.0.1:8000/Aurelian-FM8.html` を開きます。試奏版には末尾を `Play-FM8.html` にします。終了は端末でCtrl+Cです。

## エレピのアタックを作る

1. **Init Sine** を選んでAを弾きます。聞こえるのはOP1の正弦波です。
2. **OP2** を選び、**Level** を0%から60%に上げて弾き直します。OP2がOP1の位相を揺らし、同じ音程でも響きが明るくなります。
3. OP2の **Sustain** を0%、**Decay** を0.2秒にします。打鍵直後だけ倍音が出て、伸ばすと丸い音に戻ります。Decayを1秒にすると、その明るさが長く続きます。
4. **Transit EP** に切り替えます。OP4の **Level** を下げて同じフレーズを再生すると、OP3に加わっていた高域の打音を聴き分けられます。

| プリセット | 聴きどころ |
| --- | --- |
| Transit EP | 3組のペアで、芯、少しずれた余韻、短い打音を重ねたエレピ |
| Aurelian Bell | 2.71や3.51といった非整数の周波数比による金属的な響き |
| Diesel Bass | 0.5倍の低い芯と、4段直列の短いアタック |
| Drawbar Organ | 8つすべてをキャリアにした加算合成（88番）。0.5〜6倍の倍音を足したオルガン |
| Glass Choir | 1つのOP8が7つのキャリアをまとめて揺らす共有モジュレーター（87番）。少しずつずらした周波数比で厚みを出したパッド |
| FM Piano | 4組のペア。長く減衰する芯に、14倍の短い打鍵音と、わずかにずらした2本目の弦を重ねたピアノ |
| Brass Section | 1:1のペア4組を少しずつずらし、モジュレーターを遅めに立ち上げて吹き始めの膨らみを出したブラス |
| Funk Clav | 1倍と3倍の組み合わせによる鼻にかかった倍音と、短いリリースで鍵を離すと止まる弦の音 |
| Solo Trumpet | 1:1の芯に、吹き始めだけ鳴る8倍の短い息の成分を加えた単音向けのトランペット |
| Warm Pad | 0.9〜1.5秒でゆっくり立ち上がり、ずらしたキャリアでうねる柔らかいパッド |
| String Ensemble | 1:1のペアを3本ずらして重ね、オクターブ上を足した弦楽合奏 |
| Finger Bass | 押した鍵の高さで鳴る指弾きベース。3倍の短い成分で弦をはじく音を出す |
| Chime Bell | 2.76倍、5.4倍、8.93倍の非整数比を4秒以上かけて減衰させるチャイム |
| Marimba | 4倍と10倍の短い倍音と7倍のマレットの打撃音を持つ、木の鍵盤の短い響き |
| Init Sine | OP1を単独で鳴らした音作り用の初期音色 |

JD-800の音作りを参考にした8音色を、PROGRAMの **16〜23** に追加しました。既存の01〜15は同じ番号です。[Rolandのレイヤー解説](https://articles.roland.com/sound-design-the-art-of-layering-with-the-roland-jd-800/)を参考に、硬質な打音と柔らかい持続音の組み合わせ、微妙な音程差による厚みを狙っています。実機のPCM波形、フィルター、エフェクトを再現するものではなく、このFM音源で作ったオリジナルの「JD風」音色です。

| 番号 | プリセット | 聴きどころ |
| --- | --- | --- |
| 16 | JD Glass Piano | 短く硬い打鍵音と明るい芯を持つデジタルピアノ。C3〜C6付近のポップスのリフや和音に |
| 17 | JD Crystal EP | 丸いエレピの芯に、7倍の打音と薄い非整数比のベルを重ねた透明感のある音。C3〜C6付近で |
| 18 | JD Bell Mist | ガラス質のベルの後ろから柔らかい持続音が立ち上がる音色。C4〜C6付近の分散和音に |
| 19 | JD Silk Pad | 少しずつずらした3本の芯がゆっくり重なる、柔らかいパッド。C3〜C5付近の和音に |
| 20 | JD Sweep Strings | モジュレーターが遅れて立ち上がり、その後減衰することで、明るさが開いて戻る弦のパッド。和音を4〜5秒伸ばすと変化がわかる |
| 21 | JD Air Choir | 丸い基音に2〜5倍の薄い成分を重ねた、息のような上層を持つコーラス風のパッド。C3〜C5付近で |
| 22 | JD Wire Pluck | 明確な基音と短い非整数比の打音を重ねた、金属的なプラック。C4〜C6付近の分散和音やパッドのアタック層に |
| 23 | JD Soft Brass | 1:1のペアを少しずらし、吹き始めに明るさが膨らむ柔らかいシンセブラス。C3〜C5付近の和音に |

COMBIの **C06〜C08** は、これらを4つのTimbreで重ねた音色です。まず **C07 JD Crystal Air** の「フレーズ試奏」を試すと、打音からパッドへ広がる変化がわかります。**C06 JD Stage Piano** は通常打鍵とShift打鍵を比べてみてください。**C08 JD Wide Horizon** はステレオで聴くと左右の広がりがわかります。Air Choirの上層はC6までの鍵で鳴るようにしています。

「JD ピアノのポップリフ」「JD クリスタルのコード」「JD ガラスの分散和音」「JD 広がるレイヤー」「JD ブラスのコード」の5つの試奏フレーズも追加しました。プリセットを選ぶと対応する曲が自動で選ばれます。リバーブやコーラス処理は使わず、OPの周波数比とADSR、TimbreのパンとDetuneで作っています。

Transit EP、Aurelian Bell、Diesel Bass、Init Sine はFM–6から移した音色です。FM–6のOP1〜OP4はそのままの番号で、フィードバック付きのOP6はOP8に移り、余った2つのOPは音量0です。FM–6と同じ音で鳴ります。

## 発音の仕組み

オペレーターには正弦波の位相、周波数比、出力レベル、独立したADSRがあります。1サンプルずつOP8からOP1へ計算します。キャリアの出力を足し合わせて音声にし、モジュレーターの出力は接続先の位相に足します。1つのOPが複数のOPを変調することも、複数のOPから変調を受けることもできます。受けた変調は足し合わせます。A4は440 Hz。倍音は周波数比と変調の深さの両方で変化します。

88通りの配線は **web/algorithms.txt** の1行に1つずつ書いてあり、N行目がN番です。`8>7>3` は「OP8がOP7を変調し、OP7がOP3を変調する」という意味です。何も変調しないOPがキャリアになります。

| 接続 | 信号の流れ（番号はOP） | 出力するOP |
| --- | --- | --- |
| 01 | 8 → 5 → 3 → 1、7 → 5、6 → 4 → 2 → 1 | 1 |
| 42 | 8 → 1・2・4、7 → 6 → 5 → 4、3 → 2 | 1、2、4 |
| 72 | 2 → 1、4 → 3、6 → 5、8 → 7 | 1、3、5、7 |
| 87 | 8 → 1〜7 | 1〜7 |
| 88 | 8個を並列に加算 | 1〜8 |

番号はキャリアの少ない順に並んでいます。同じキャリア数の中では、段の深いものが先です。88通りは次の2種類で、番号の付け替えだけで重なる配線はありません。

| 種類 | 数 | 決め方 |
| --- | --- | --- |
| 木構造 | 78 | 各OPは1つのOPだけを変調する。最大4段、1つのOPへの変調は2つまで、枝分かれは2か所まで |
| 共有モジュレーター | 10 | OP8が、OP1〜OP7で作った3〜7本の並列スタック（各4段まで）をまとめて変調する |

いずれもOP8は自分自身へフィードバックできます。64音が使用中なら、リリース中の最古の声、その次に打鍵時刻の最も古い声を再利用します。PC鍵盤の通常打鍵とShift打鍵には異なるベロシティを割り当てています。

FM–8は、8オペレーター・88アルゴリズムという規模を参考にした独自の配線表です。特定の機種のアルゴリズム表を再現したものではありません。エンベロープは秒単位の線形ADSRです。プリセットはオリジナルです。MIDI機器からはノート、サステインペダル、ピッチベンド、モジュレーション、プログラムチェンジなどを受け取れます。SysEx音色の読み込み、TimbreごとのMIDIチャンネル、RPNによるベンド幅の受信、DAWプラグイン、実機の量子化特性の再現は未実装です。

| examples/first_patch.rs | Rust音源を直接呼んでWAVへ書く最小の聴き比べ |
| web/presets.json | 音色。8つのOPそれぞれの配列は周波数比、レベル、Attack秒、Decay秒、Sustain、Release秒の順 |
| web/algorithms.js | 配線表の解釈とFM–6音色の変換。画面とAudioWorkletの両方に埋め込む |
| web/midi.js | MIDI信号の解釈、受信チャンネル、サステインペダル、ピッチベンドとモジュレーション。ブラウザーの機能を使わないのでNodeでテストできる |
| web/combination.js | Timbreの既定値、範囲、鍵域とベロシティの判定、パン。画面とAudioWorkletの両方に埋め込む |
| web/combinations.json | Combinationのプリセット。16個のTimbreそれぞれに設定とProgramを丸ごと持つ |
| web/phrases.json | 試奏フレーズ。各音は開始拍、MIDIノート番号、長さ（拍）、ベロシティの順。`beat` は1拍のミリ秒、`suits` は合わせるプリセット名 |
| web/instrument.html | 日本語の操作画面、パッチの保存、鍵盤と試奏フレーズ |
| web/processor.js | AudioWorklet、Rust音源との接続、準備不要の試奏版用音源 |
| src/bin/build-instrument.rs | Rust音源と画面を単一のHTMLへまとめ、試奏版も書き出すビルダー |
| tests/scope.cjs | 試奏版音源の波形モニター、配線表、FM–6音色の変換のテスト（`node tests/scope.cjs`） |
